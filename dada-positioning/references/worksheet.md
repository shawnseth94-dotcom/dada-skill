## 1. 访谈提问库

按阶段选用问题，不要一次全部询问。

### A. 当前状态

- 你现在主要做什么业务？产品、客单价和主要客户分别是什么？
- 过去 12 个月，客户主要从哪里来？哪一步最卡？
- 你对当前定位最不满意的具体表现是什么？
- 你正在犹豫哪些方向？为什么会考虑它们？

### B. 结果与能力圈

- 过去五年，你反复做成过哪三件有结果的事？
- 哪件事即使换了行业、公司或产品，你仍然做得比多数人好？
- 别人通常为什么问题主动来找你？他们最后得到过什么结果？
- 你持续赚到钱的核心理由是什么？请用案例和数字证明。
- 哪些能力只是你喜欢，哪些已经被客户、雇主或结果验证？
- 如果只能保留一项可变现能力，你会留下什么？

### C. 经历与共情

- 你经历过哪些从 A 到 B 的转变？
- 哪段低谷或弯路让你特别理解某类人的处境？
- 你的行业、地域、家庭、职业或人生阶段，让你天然属于哪些群体？
- 哪类客户和你聊天时最容易说“你真的懂我”？为什么？
- 哪类客户即使有钱，你也很难理解或不想长期服务？

### D. 价值观

- 你所在行业里，哪种常见做法最让你反感？
- 哪个多数同行相信的观点，你明确不同意？
- 为了结果，你绝不会牺牲什么？
- 你愿意因为坚持哪个原则而失去一部分客户？
- 客户过去因你的哪句话、哪种态度决定信任你？

### E. 人群

- 请描述一个最理想的真实客户，而不是一类抽象标签。
- 他处于什么行业、角色、规模或人生阶段？
- 问题通常在什么事件发生后变得紧急？
- 谁使用、谁付钱、谁做购买决定？
- 他现在为替代方案花多少钱、时间或机会成本？
- 你通过什么渠道能找到十个这样的人？
- 明确说出三类你不服务的人。

### F. 需求与结果

- 他嘴上说想要什么？真正阻碍他的是什么？
- 如果问题不解决，三个月或一年后会付出什么代价？
- 他购买的不是“课程/咨询”，而是哪种变化？
- 结果可以用什么数字、行为、里程碑或状态证明？
- 你用什么独特机制促成这个结果？已有案例吗？
- 市场上他还会选择谁或什么替代方案？

## 4. 最小验证画布

| 项目 | 内容 |
|---|---|
| 定位假设 | 我凭借……帮助……解决……实现…… |
| 最大不确定性 | 这项定位最可能错在哪里？ |
| 测试对象 | 哪 5–10 位真实目标用户？ |
| 测试动作 | 访谈 / 内容 / 邀约 / 预售 / 付费诊断 |
| 测试周期 | 7–14 天 |
| 成功指标 | 例如：10 人中 4 人承认问题紧迫、2 人愿意付费 |
| 失败指标 | 例如：没人承认问题、只有点赞没有咨询 |
| 反馈记录 | 用户原话、异议、替代方案、愿付价格 |
| 下一步 | 坚持 / 修改人群 / 修改需求 / 放弃假设 |

内容测试要看有效咨询、目标用户占比和下一步行动，不单看播放量。访谈要问过去行为和真实支出，不只问“你会不会买”。

## 6. 常见误区与纠偏

| 误区 | 识别信号 | 纠偏动作 |
|---|---|---|
| 用兴趣代替能力 | “我喜欢心理学，所以做疗愈” | 回到已有结果；兴趣只用于切人群或内容表达 |
| 人群过宽 | 宝妈、老板、女性、有需求的人 | 描述一个真实客户、触发场景、预算和排除人群 |
| 把手段当结果 | 健身、咨询、做 IP、学 AI | 追问客户买完后发生什么可验证变化 |
| 盲追风口 | 行业热但没有能力与差异 | 寻找能力圈与新趋势的交叉点，或放弃 |
| 只看流量 | 播放高但没有目标咨询 | 统计目标客户占比、有效线索、成交与交付结果 |
| 过度量化 | 为好听承诺无法控制的结果 | 改为可验证里程碑，并说明条件与边界 |
| 一次定终身 | 因不完美迟迟不开始 | 同时保留 1–2 个假设，用 7–14 天小测迭代 |
| 来者不拒 | 任何付钱的人都接 | 明确拒绝标准，让产品、内容和交付保持一致 |
