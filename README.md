# dada-skill

达达（Shawn）的公众号内容创作工具箱，给 [Claude Code](https://claude.com/claude-code) 用的一组 Skill。

这套工具不是为了让 AI 替你写文章省力气，是把一个真实创作者长期积累的判断标准拆解成可复用的规则。装好之后，从选题到正文到标题封面，每一步都有对应的工具，每个工具只干一件事，边界写得很死。

---

## 怎么装

不需要写代码，三步。

```bash
git clone git@github.com:shawnseth94-dotcom/dada-skill.git
```

把克隆下来的每个 skill 文件夹，放进你的 `~/.claude/skills/` 目录。或者直接打开 Claude Code，把上面这行 clone 命令粘进去，告诉它：

> 把这个仓库克隆下来，把里面的 skill 都装进我的 `~/.claude/skills/` 目录。

装完新开一个对话，输入 `/`，就能看到这些工具出现在列表里。

## 工具一览

### 入口

| Skill | 作用 |
|---|---|
| `dada` | 内容工具箱主入口，自己不做内容不做分析，只负责判断需求并路由到对应工具 |
| `dada-workflow` | 内容生产全流程管理员，不亲自做内容，检测你当前在哪个阶段，调用对的工具，推动文章从零到发布就绪 |

### 选题与洞察

| Skill | 作用 |
|---|---|
| `dada-mining` | 从晨间日记和录音语料里挖洞察，不生成内容，只挖，洞察必须来自原文 |
| `dada-insight` | 洞察引擎，输入一个话题，找常识再找隐隐的怀疑，生成穿透性洞察，最后落成标题 |

### 标题与开头

| Skill | 作用 |
|---|---|
| `dada-wechat-hook` | 公众号开头优化，诊断开头问题，前 120 字完成推送预览，前 300 字让人决定继续读 |
| `dada-wechat-title` | 公众号标题，从 32 个验证过的公式里匹配最适合的，并解释为什么选这个 |
| `dada-xhs-hook` | 小红书开头优化，专为前两行留人设计 |
| `dada-xhs-title` | 小红书标题，公式匹配器，每个标题都能追溯到具体公式编号 |

### 正文与风格

| Skill | 作用 |
|---|---|
| `dada-writer` | 公众号长文写作，先讲经历再讲道理，情绪往下沉不往上飙 |
| `dada-style` | 把任意文字改写成达达的声音和腔调 |
| `dada-knowledge-boost` | 知识增厚，必须在人味草稿确认之后才用，加金句引用、证据类比、反直觉转折 |
| `dada-guide` | 干货指南生成器，步骤必须从洞察推导出来，不是洞察加步骤两张皮 |

### 把关与用户洞察

| Skill | 作用 |
|---|---|
| `dada-identity` | 身份过滤器，在发任何内容之前，判断这篇文章是强化了核心身份，还是在悄悄稀释它 |
| `user-insight` | 用户洞察引擎，输入行业背景和已服务案例，输出用户分层、痛点矩阵、核心用户识别，判断标准是谁离激发购买意识越近谁就离成交越近 |
| `pain-to-voice` | 用户心里话翻译工具，把抽象、总结性的痛点描述，翻译成用户真实说话的方式 |

### 延伸内容

| Skill | 作用 |
|---|---|
| `dada-moments` | 朋友圈文案工具，朋友圈不是缩短版公众号，是另一种媒介 |
| `dada-chatroom-heart` | 心学聊天室，王阳明 × 老子 × 艾伦·瓦茨三人对话，Claude 做判官 |

---

## 一个典型流程

选题用 `dada-mining` 或 `dada-insight` 挖出来，正文用 `dada-writer` 写，标题用 `dada-wechat-title` 配，开头用 `dada-wechat-hook` 优化，写完想加深度再用 `dada-knowledge-boost`。也可以直接说「帮我走一遍全流程」，交给 `dada-workflow` 调度。

## 说明

这套工具的骨架是达达本人的判断标准，规则定死，不允许越界。装是三分钟的事，真正花时间的是想清楚每个工具该守住什么边界——这部分你拿过去也得自己填。
